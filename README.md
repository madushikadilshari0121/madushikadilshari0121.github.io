# Portfolio

Static portfolio site (index.html + images/). Open index.html in VS Code with the Live Server extension to preview.

## Publish on GitHub Pages
1. Create a repo named `madushikadilshari0121.github.io` (public) on GitHub.
2. In this folder run:
   git init
   git add .
   git commit -m "Add portfolio"
   git branch -M main
   git remote add origin https://github.com/madushikadilshari0121/madushikadilshari0121.github.io.git
   git push -u origin main
3. GitHub repo > Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4. Your site appears at https://madushikadilshari0121.github.io in a minute or two.
